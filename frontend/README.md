# Frontend

Espaco reservado para a interface do Personal Finance. Ainda nao existe
aplicacao executavel nem framework escolhido. A implementacao esta prevista
no M6 do [roadmap](../docs/roadmap.md).

A interface consumira a API HTTP do backend, sem acesso direto ao banco.
Telas previstas: movimentacoes, contas, importacao, orcamento e resumo mensal;
investimentos e desejos serao adicionados nas respectivas etapas.

Na implementacao, definiremos tecnologia, comandos, URL da API e a integracao
local (proxy ou CORS). Dependencias e configuracoes da interface ficarao aqui.
